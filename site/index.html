Voice-Hermes · Wake-Word Agent

Rex

Always-listening voice layer for your Hermes agent — say the keyword, Hermes runs it with full system access. Offline. Private. No cloud.

A local daemon that catches your wake word, transcribes your instruction with an offline model, and hands it to the full Hermes agent — files, terminal, browser, computer-use — then speaks the answer back. A JS control layer drives it over a local bridge.

Status

Verified working end-to-end. A spoken "Hey Hermes, what is 2 plus 2?" flowed through offline STT → wake-word gate → the full Hermes agent → "2 plus 2 equals 4." — spoken back by TTS. How it works
mic → VAD
→
offline STT
→
wake gate
→
hermes chat -q
→
TTS reply

STT uses the faster-whisper model already bundled inside Hermes's own Python venv — no cloud, no extra model download. The wake gate matches your keyword and splits off the command that follows. The reply is spoken back with edge-tts over sounddevice.

Run it

Start the JS control layer (it owns the Python bridge):

cd C:\Users\Saura\rex && node src\js\cli.mjs --text "hey hermes, what is 2 plus 2"

Or start the Python audio daemon directly (needs a real mic):

C:\Users\Saura\AppData\Local\hermes\hermes-agent\venv\Scripts\python.exe C:\Users\Saura\rex\src\py\daemon.py --mic

Self-test a recorded clip without a mic: python daemon.py --selftest sample.wav

05
Safety

Always-on mic + agent-with-terminal is powerful. Hermes runs with approvals.mode: smart so destructive tool calls still prompt you, and a dangerous-command guard blocks obviously destructive spoken instructions pending confirmation. Wake words, guard toggle, and TTS voice live in config.json.
